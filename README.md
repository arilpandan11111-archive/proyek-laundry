# 🧺 Laundry Management System (Ultimate Edition)

Aplikasi dashboard manajemen laundry berbasis desktop yang dirancang untuk mengelola data pelanggan secara efisien dengan implementasi algoritma yang optimal.

## 🌟 Fitur Utama
- **Auto-Generate Data:** Menghasilkan 100 data pelanggan dummy secara acak untuk keperluan pengujian sistem.
- **Quick Sort:** Algoritma pengurutan data berdasarkan Nama dan Berat cucian dengan kompleksitas waktu O(n log n).
- **Search Engine:** Fitur pencarian pelanggan secara *real-time* yang memudahkan pengelolaan data.
- **Live Dashboard:** Statistik dinamis yang menampilkan total berat cucian dan jumlah layanan aktif secara otomatis.
- **Responsive UI:** Antarmuka modern yang dikembangkan menggunakan `ttkbootstrap` untuk pengalaman pengguna yang lebih baik.
